# houjin-tax-lite

Claude CodeとCodex向けの、e-Taxのエラーとつまずきを探す無料スキルです。
法人税や消費税の準備中に出た番号やメッセージから、次に確かめる資料や表示を整理します。

## できること

- エラー番号、帳票項目の識別子、症状から15項目の索引を引く。
- 帳票の計算チェック、入力の不反映、証明書、カード、利用者の不一致を切り分ける。
- 確認済みの事実と原因候補を分け、本人が次に確認することを示す。

公式の全エラーを網羅するものではありません。同じ番号でもメッセージが異なる場合があります。
法人税固有の帳票項目は、消費税の帳票には当てはめません。

## 入れ方

このリポジトリをダウンロードし、`houjin-tax-lite`フォルダーを、作業するプロジェクトの次の場所へコピーします。
リポジトリ全体ではなく、`SKILL.md`と`references/`を含むフォルダーをコピーしてください。
同名のスキルがある場合は、内容を確認してから扱ってください。

### Claude Code

```text
プロジェクト/
└── .claude/skills/houjin-tax-lite/
    ├── SKILL.md
    └── references/errors.md
```

コピー後、そのプロジェクトでClaude Codeを起動します。
`/houjin-tax-lite`で呼び出すか、症状を伝えてこのスキルを使うよう依頼します。
配置仕様は[Claude Code公式ドキュメント](https://code.claude.com/docs/en/skills)を参照してください。

### Codex

```text
プロジェクト/
└── .agents/skills/houjin-tax-lite/
    ├── SKILL.md
    └── references/errors.md
```

コピー後、そのプロジェクトでCodexの新しいセッションを開始します。
`$houjin-tax-lite`を指定するか、スキル名と症状を伝えて利用を依頼します。
配置仕様は[Codex公式ドキュメント](https://learn.chatgpt.com/docs/build-skills)を参照してください。

## 使い方

```text
houjin-tax-liteを使って確認先を探してください。
インストール版e-Taxソフトの別表四で、
AQC00330を伴う計算結果のエラーが出ています。
確認できた事実と原因候補を分けてください。
```

番号に加え、伏字にしたメッセージ本文、発生した操作、税目、対象年度、ソフトの版が分かると切り分けに役立ちます。
`AQC00330`のような帳票項目の識別子も検索できます。
必要な確認まで分かっているときは、[索引を直接読む](houjin-tax-lite/references/errors.md)こともできます。

暗証番号、パスワード、利用者識別番号、マイナンバー、口座番号は入力しないでください。
画面やログを共有する場合は、氏名、法人名、住所、金額なども伏せてください。

## できないこと

税務相談、申告の代行、税務上の適否の判定は行いません。
申告書の作成手順、確認表一式、詳細な失敗事例集、申告データ生成器は含みません。
税区分、制度の選択、申告内容は、本人または税理士が判断してください。

このスキルは、ログイン、証明書の登録変更、署名、送信、納付を実行しません。
操作が必要な場合は本人へ渡します。結果不明の送信を再実行しません。
AIの回答やソフトの正常受付は、税務上の正しさを保証しません。
利用時には対象年度の公式情報と、実際の表示を確認してください。

## 有料版との違い

無料版は、いま出ているエラーや症状から確認先を探す部分に絞っています。
決算から申告に向けた手順、確認表、事例集をまとめた全部入りは、noteの有料版（`https://note.com/smartmatching/n/n4b60131812c3`）で案内します。
有料版も税務相談や申告代行を提供するものではありません。
